3. GitHub Action 추가

자동 검증을 위해 워크플로우 파일을 추가했습니다: .github/workflows/reuse.yml

name: REUSE Compliance Check
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: REUSE Compliance Check
        uses: fsfe/reuse-action@v5

✅ 검증 방법 (Verification)

이제 코드를 GitHub에 푸시하거나 Pull Request를 생성할 때마다 자동으로 검사가 수행됩니다.

  1. GitHub 리포지토리의 Actions 탭으로 이동합니다.

  3. 녹색 체크 표시(✅)가 뜨면 모든 파일이 SPDX 라이선스 정보를 올바르게 포함하고 있는 것입니다.
